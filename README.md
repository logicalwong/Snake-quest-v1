# Snake Quest · Game Boy Edition

A modern, web-based adaptation of the classic Snake game, wrapped in a nostalgic Game Boy-style interface. Play solo or race against an AI opponent to secure the highest score!

## Features

- **Retro Aesthetic**: Authentic Game Boy console design with a functional D-pad, Start/Select buttons, and a glowing power LED.
- **AI Opponent**: Compete against an intelligent AI snake on the same board.
- **Multiple Difficulties**: Choose between Easy, Medium, and Hard modes to match your skill level.
- **Responsive Design**: Playable on both desktop and mobile devices with touch/swipe controls and clickable on-screen buttons.
- **Score Tracking**: Keeps track of your score, the AI's score, and your all-time high score.

## How to Play

### Controls

**Desktop:**
- **Arrow Keys**: Move the snake (Up, Down, Left, Right).

**Mobile/Touch:**
- **Swipe**: Swipe on the game screen to change direction.
- **On-Screen D-Pad**: Tap the on-screen Game Boy directional buttons.

**Game Buttons:**
- **Start / A Button**: Start or Restart the game.
- **Select / B Button**: Pause or Resume the game.

### Gameplay

1. Select your preferred difficulty from the side panel.
2. Press **START** to begin.
3. Guide your green snake to eat the food while avoiding the walls, your own tail, and the AI snake.
4. Outlast and outscore the AI opponent!

## Project Structure

- `index.html`: The main HTML structure, containing the Game Boy console layout and side panels.
- `style.css`: The CSS styling that brings the retro Game Boy design to life.
- `script.js`: The game logic, including movement, collision detection, score tracking, and AI behavior.

## Running the Game

Simply open `index.html` in any modern web browser to start playing. No build tools or server setup required!
